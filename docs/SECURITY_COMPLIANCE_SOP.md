# NKUStudy 安全合规内部处理规程（SOP）

> 依据：《网络安全法》《网络安全等级保护基本要求》及全国互联网安全管理服务平台安全评估整改要求制定。
> 版本：v1.0（2026-09-23） · 安全负责人：平台主管理员（Shview）

## 一、角色与职责

| 角色 | 人员 | 职责 |
|---|---|---|
| 安全负责人 | 主管理员（accounts.manage 权限持有者） | 收到依法调取要求后的真实性核验、审批 |
| 数据导出人 | 被授权的管理员（law.manage 权限） | 在后台「依法调取」执行查询/导出 |
| 内容审核员 | content.moderate 权限持有者 | 评价/反馈/举报的审核处置 |

## 二、违法有害内容处置流程

1. 用户通过「违法有害信息举报」提交（关联 URL/内容 ID/账号 + 原因），内容默认待审核、永不公开展示；
2. 审核员在后台「反馈与举报」处置：驳回 / 隐藏 / 删除 / 完成不成立；
3. 严重违规：在「小程序用户」或举报条目上执行封禁（blocked），封禁账号立即无法登录与发布；
4. 全部处置动作写入管理员审计日志（操作人/时间/路径/状态）与条目 handled_by/handled_at 字段。

## 三、依法调取协助流程

1. **核验**：安全负责人核验调取单位公函/法律文书与经办人身份，留存扫描件；
2. **授权**：安全负责人确认后，指派具备 law.manage 权限的管理员执行；
3. **导出**：在后台「依法调取」按账号（user_id/手机号/OpenID）或内容 ID 查询并导出 JSON（含账号信息与认证状态、原始内容、发布时间、来源 IP、操作日志、处置记录）；
4. **留痕**：每次查询与导出自动写入 `law_enforcement_logs`（操作人/时间/条件/结果概要），审计日志同步记录；
5. **确认与归档**：安全负责人核验导出内容与范围最小必要后交付，公函、导出文件与调取记录一并存档不少于 6 个月。

## 四、日志留存

- 用户安全日志（`user_security_logs`，含原始 IP）保留 ≥400 天，每日自动清理超期记录；
- 系统日志（journald，含 Caddy 访问日志）`MaxRetentionSec=200d`；
- 管理员审计日志长期保留（超量自动归档）；
- 自动备份保留策略 ≥6 个月。

## 五、用户实名（后台实名、前台自愿）

- 发布评价/反馈/举报必须为已登录且完成微信手机号验证（getPhoneNumber）的账号；
- 手机号仅存服务器（0600 SQLite），不对外公开，接口仅返回掩码；
- 依法调取时可通过 user_id ↔ 手机号 ↔ OpenID 关联发布人身份。
