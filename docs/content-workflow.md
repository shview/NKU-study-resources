# NKUStudy 内容维护流程

## 生产内容的唯一入口

生产环境的课程、资源索引、首页、关于、参与、友链、评价与反馈都只允许由网站管理端维护。管理端完成权限校验、字段校验、审核与站点重建；维护人员不要登录服务器直接编辑 JSON，也不要从本地覆盖生产数据。

微信小程序只读取公开接口并提交普通用户操作。它不提供内容管理功能，`/api/v1` 也不得映射或代理任何 `/admin-api` 路由。

## 发布边界

- 生产数据存放于受控持久化目录；完成 `DATA_DIR` 改造后目标目录为 `/var/lib/nkustudy`。
- 代码发布只同步源码，不能携带 `src/data/*.json`、凭据、数据库、日志、备份或资源文件。
- 网站重建必须读取服务器上的最新受控数据。若缺少必需文件，应中止，不得自动改用示例数据。
- 课程资料继续由 R2 提供，密钥只保存在服务器环境变量中。小程序 API 只返回经过白名单整理的公开下载地址。

## 隔离测试数据

`src/data/fixtures` 仅保存人工审查过、无真实评价、无联系方式、无访问记录、无内部路径和无密钥的最小测试数据。运行 `npm run build:fixtures` 时，脚本会拒绝覆盖任何已存在的 `src/data/*.json`，临时放入 fixture，构建到 `dist-fixture` 后立即清理。

fixture 构建只用于本地或 CI 验证，严禁发布 `dist-fixture`，也严禁把 fixture 写回网站管理端。

## 内容变更核验

管理端写入后应运行内容校验和生产候选构建，再检查网站与旧接口。正式发布流程和回滚要求见 `docs/DEPLOYMENT.md`。如需变更 JSON 结构，应先修改服务端读写、校验和迁移程序，再由管理端执行迁移；不得直接批量替换线上文件。
